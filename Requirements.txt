# Exusiai Desktop Pet - Requirements
# 当前基线版本：1.5.4
# 文档用途：记录当前完整需求与截至 v1.5.4 的更新历史；本项目运行和构建均不依赖 Python 包。

[项目目标]
- 制作为 Windows x64 使用的桌宠可执行程序。
- 优先降低程序体积、内存占用与后台资源消耗。
- 使用原生 Win32 C++ 实现，输出单个 Exusiai.exe；用户无需安装额外运行库。
- 程序只能同时运行一个实例。
- 桌宠窗口透明、无任务栏按钮、不抢占当前应用焦点。

[时装与动画]
- 提供四套时装：新约、寻翼之歌、城市骑手、午夜邮差。
- “新约”沿用内部 default 资源标识，但用户界面不得显示为“默认”。
- 午夜邮差与城市骑手共用语音池、Sit 定位及通用状态逻辑。
- 动作状态包括：Interact、Move、Relax、Sit、Sleep、Special。
- 待机基础状态必须循环 Relax，不使用 Default 作为待机动画。
- 新约时装没有独立 Special 动画；要求 Special 时回退为 Relax。
- 更换时装时尽量保持当前动作和动画进度。
- GIF 使用稳定的整段动画画布尺寸和逐帧偏移渲染，不能因帧尺寸或帧偏移变化造成周期性颤动。
- 模型普通站立、移动等状态下调 3 px，使素材可见区域的脚底贴合桌面工作区下沿。

[自动状态]
- 自动模式下以 Relax 为主要待机状态。
- 自动移动每 10–30 秒随机触发一次，每次持续约 1.8–5 秒，速度约 50 px/s。
- 非活动达到约 60 秒后允许随机进入 Sit；达到约 120 秒后允许随机进入 Sleep。
- 非新约时装允许低概率随机进入 Special。
- 到达桌面左右边缘时不得越界；自动移动可以转向。
- 固定状态支持：Auto、Relax、Sit、Sleep、Special。
- 选择固定状态后持续循环该状态，并关闭自动移动与随机状态切换。

[鼠标交互]
- 左键拖动桌宠可改变水平位置，并将位置保存到 Exusiai.ini。
- 左键短按进入 Interact 动画并播放当前时装的交互语音。
- Interact 动画播放期间重复点击不得重新开始该动画。
- 透明像素区域允许鼠标穿透，只有可见角色区域响应交互。
- 右键打开桌宠菜单。

[键盘移动]
- 右键菜单“移动”用于开启或关闭键盘操控模式。
- 开启后使用 A/D 或左右方向键控制水平移动。
- 按住按键时使用 Move 动画；松开按键后回到 Relax。
- 同时按下左右方向键时视为停止移动。
- 键盘读取不得拦截其他程序的按键输入。
- 键盘操控模式下不得进入 Sit、Sleep、Special，也不得触发自动移动。
- 键盘操控到达屏幕边缘后停止，不能自动反向弹走。
- Interact 动画与交互语音仍可使用。
- 开启键盘操控时退出专注模式；选择固定状态或开启专注模式时退出键盘操控。
- 按住 Shift 时移动速度提高到普通速度的 2.5 倍。

[作战模式]
- 通过右键菜单“作战/退出作战”进入或退出作战模式，不设置 Q 或 Alt+Q 快捷键。
- 作战模式使用四套时装各自的 Start、Idle、Attack 和 Die 动画；新约与寻翼之歌还包含 Skill 动画。
- J 触发普攻，K 触发技能；A/D 或左右方向键控制朝向。
- 在普攻或技能 Loop 状态再次按下对应按键时，只额外重复一次 Loop；连续多次按下仍只排队一次。
- 退出作战应等待当前攻击或技能动作安全结束，再播放 Die 和淡出过渡，不能卡死。
- 转身过渡时长为 225 ms（较上一实现缩短 25%）。
- 作战过程中不得被普通闲置、固定状态、专注模式或键盘移动逻辑打断。

[专注模式]
- 右键菜单提供可勾选的“专注模式”。
- 开启后桌宠自动走向距离当前位置较近的桌面左边缘或右边缘。
- 到达边缘后切换到 Sit 并保持不动。
- 坐在左侧时角色朝右；坐在右侧时角色朝左，始终面向屏幕内部。
- 专注模式禁用闲置语音，但保留左键点击触发的交互语音。
- 专注模式关闭自动移动和键盘操控。
- 寻翼之歌在专注 Sit 时使用贴边定位，角色向屏幕外侧偏移，使身体紧贴边缘，不保留参考图红框所示空隙。

[任务栏与角色定位]
- 新约、城市骑手在 Sit 状态下以臀部坐在任务栏上。
- 寻翼之歌在非专注 Sit 状态下同样以臀部坐在任务栏上。
- Sit 状态的腿部必须显示在任务栏前方，不能被任务栏遮挡。
- 寻翼之歌专注 Sit 使用独立的屏幕边缘定位，不与非专注 Sit 共用横向偏移。
- 新约 Sit 基准偏移：109 px。
- 城市骑手 Sit 基准偏移：104 px。
- 寻翼之歌非专注 Sit 基准偏移：108 px。
- 寻翼之歌专注 Sit 屏幕外侧偏移：90 px。
- Windows 任务栏重建、显示设置变化或工作区变化后必须重新计算位置。
- 所有时装的 Sleep 状态统一向下偏移约 36 px，使躺卧姿态贴近任务栏，不再浮空。

[语音]
- 每套时装分别使用对应的闲置语音池和交互语音池。
- 城市骑手与午夜邮差：A1–A9 为闲置语音，A10–A13 为交互语音。
- 新约：B1–B9 为闲置语音，B10–B12 为交互语音。
- 寻翼之歌：C1–C10 为闲置语音，C11–C13 为交互语音。
- 程序启动时默认静音。
- 静音时立即停止语音并隐藏字幕。
- 非静音状态下，点击桌宠立即播放交互语音；专注模式不阻止交互语音。
- 闲置语音仅在非专注模式，并且当前状态不是 Move、Sleep、Interact 时触发。
- Relax、Sit、Special 状态允许触发闲置语音。
- 语音最小/最大间隔可设置，范围均为 1–3600 秒，默认 30–150 秒随机。
- 设置的时间间隔定义为：上一段语音实际播放结束后，到下一段语音开始前的等待时间。
- 下一次语音计划时间必须按“当前语音时长 + 随机设置间隔”计算，不能从当前语音开始时直接只计算间隔。
- 如果计划时间到达时处于禁止闲置语音的状态，则等待到重新满足触发条件，不得提前播放。
- 更换时装时停止当前语音，并按照新时装的语音池重新计时。
- A9 字幕中的“主”显示为“神明”；B5 字幕中的所有“主”显示为“神明”。

[音量]
- 右键菜单提供“静音”和“音量控制...”。
- 音量控制窗口提供 0–100% 滑条和当前百分比显示。
- 默认保存音量值为 70%，但程序启动状态仍为静音。
- 音量设置保存到 Exusiai.ini。

[字幕]
- 播放语音时，在桌宠身旁显示对应字幕。
- 字幕使用黑体（SimHei）、红白渐变文字和描边效果。
- 字幕根据桌面边界自动选择桌宠左侧或右侧，不能超出工作区。
- 字幕淡入约 0.5 秒，淡出约 0.5 秒。
- 字幕显示时间与对应语音时长匹配。
- 静音或语音停止时不显示字幕。
- 字幕窗口不得接收鼠标输入，也不得抢占焦点。

[右键菜单]
- 使用方案一的紧凑原生菜单布局。
- 菜单根据 Windows 应用主题自动切换深浅色；深色模式使用黑色背景和白色文字。
- 每次打开菜单及系统主题变化时重新读取主题设置。
- 菜单顺序：
  1. 更换时装 > 新约 / 寻翼之歌 / 城市骑手 / 午夜邮差
  2. 当前状态 > 自动 / Relax / Sit / Sleep / Special
  3. 移动
  4. 分隔线
  5. 专注模式
  6. 始终置顶
  7. 静音
  8. 音量控制...
  9. 分隔线
  10. 设置...
  11. 退出程序
- “移动”“专注模式”“始终置顶”“静音”使用勾选状态显示是否开启。

[设置窗口]
- 可设置闲置语音最小间隔和最大间隔。
- 最大间隔不能小于最小间隔。
- 可选择固定状态：Auto、Relax、Sit、Sleep、Special。
- 输入非法时显示提示且不应用设置。
- 使用 Segoe UI、清晰的标题、统一间距和较大的输入控件及按钮。
- 设置窗口的背景、文字、输入框、组合框和标题栏跟随 Windows 深浅色主题。
- 设置窗口明确提示语音间隔从上一段播放结束后开始计算。
- 提供全局 GIF 播放速度滑块，范围 1.0×–2.0×、步进 0.1×，并保存到 Exusiai.ini。

[始终置顶与任务栏层级]
- 右键菜单提供可勾选的“始终置顶”，默认开启。
- 桌宠及字幕窗口应保持在普通窗口和任务栏前方。
- 仅在置顶样式丢失或检测到任务栏实际位于桌宠上方时重新设置层级，避免周期性强制重排导致颤动。
- 若系统无法可靠检测任务栏遮挡，必须优先保证 Sit 腿部显示在任务栏前方。
- 打开设置窗口或音量窗口时，不执行会干扰窗口操作的重复层级重排。

[稳定性]
- 使用固定动画画布渲染 GIF，各帧复制到其元数据指定偏移位置。
- 切换帧时桌宠窗口大小与锚点不得改变，消除约每 3 秒出现一次的位置抖动。
- 没有实际位置变化时不得重复调用窗口移动。
- 没有层级异常时不得重复调用置顶操作。
- 桌宠水平位置必须限制在当前 Windows 工作区内。
- 显示设置、任务栏设置变化后重新读取工作区。
- 动画使用高精度 Waitable Timer 与基于 QueryPerformanceCounter 的累计时间轴推进。
- 帧推进依据实际经过时间补帧/跳帧，不直接将每帧延时反复取整。

[持久化]
- Exusiai.ini 保存：当前时装、水平位置、音量、语音最小间隔、语音最大间隔、固定状态、专注模式、始终置顶、GIF 播放速度。
- 静音状态不持久化；每次启动均默认静音。
- 键盘操控模式不持久化。

[构建与兼容性]
- 目标格式：PE32+、Windows x86-64 GUI。
- 使用 C++17、MinGW-w64、静态链接 libgcc/libstdc++。
- 系统 DLL 依赖限定为 Windows 自带组件：COMCTL32、GDI32、KERNEL32、msvcrt、ole32、SHLWAPI、USER32、WINMM。
- 所有 GIF、图标、语音和字幕数据嵌入 Exusiai.exe。
- 构建完成后必须验证 MZ 文件头、x64 PE 格式、版本资源和 SHA-256 校验。
- 输出文件名固定为 Exusiai.exe。

[验收标准]
- 连续运行时角色不应周期性横向或纵向颤动。
- 所有动画切换时窗口锚点稳定。
- 四套时装的站立脚底贴合桌面下沿。
- 四套时装的非专注 Sit 臀部位于任务栏上沿，腿部显示在任务栏前方。
- 四套时装的 Sleep 均按参考图下移并贴近任务栏。
- 寻翼之歌专注 Sit 在左右边缘均朝向屏幕内部并紧贴屏幕边缘。
- 键盘移动期间不出现 Sit、Sleep、Special。
- 闲置语音的最短等待从上一段语音播放结束时开始计算。
- 专注模式无闲置语音，但点击仍可播放交互语音。
- 重复点击不重新播放 Interact 动画。
- 关闭“始终置顶”后不得继续强制置顶。
